3|500|TOEIC Part 5: word form (noun suffixes)|品詞の選択:名詞の語尾|空所が冠詞・形容詞・所有格のあとにあり名詞が必要なら、-tion / -ment / -ness / -ity / -er などの名詞形を選ぶ。|the + 名詞;;形容詞 + 名詞;;所有格 + 名詞|The company announced the expansion of its shop.=>会社は店の拡張を発表しました。;;Her decision surprised everyone.=>彼女の決定は皆を驚かせました。||the expand / the decide
3|500|TOEIC Part 5: word form (adjective suffixes)|品詞の選択:形容詞の語尾|be動詞のあと・名詞の前の空所には -ful / -ive / -able / -ous / -al などの形容詞形が入る。|be + 形容詞;;形容詞 + 名詞|The new system is reliable.=>新しいシステムは信頼できます。;;We offer affordable rooms.=>手頃な価格の部屋を提供しています。||The system is reliably.
3|500|TOEIC Part 5: word form (adverb -ly)|品詞の選択:副詞(-ly)|動詞・形容詞・文全体を修飾する語は副詞形にする。主語と動詞の間や動詞の後ろに置かれる。|V + 副詞;;副詞 + 形容詞;;be + 副詞 + p.p.|The manager quickly replied.=>部長はすぐに返信しました。;;The shop is highly rated.=>その店は高く評価されています。||He quick replied.
3|600|TOEIC Part 5: to + base verb|to のあとの動詞の原形(不定詞)|不定詞の to のあとには動詞の原形が入る。名詞や -ing 形は入らない。|to + V;;in order to + V;;be able to + V|Please remember to submit the form.=>用紙の提出を忘れずにお願いします。||remember to submitting / able to submission
3|600|TOEIC Part 5: preposition + -ing|前置詞のあとの -ing 形|前置詞のあとに動詞を置くときは動名詞(-ing)にする。by / for / after / before / without などが典型。|前置詞 + V-ing;;by + V-ing;;without + V-ing|We saved time by using the new system.=>新しいシステムを使って時間を節約しました。||by use / by to use
3|500|TOEIC Part 5: modal + base verb|助動詞のあとの動詞の原形|can / will / must / should などのあとは、主語が何であっても動詞の原形が続く。|助動詞 + V;;助動詞 + not + V|You can pay by card.=>カードで支払えます。||You can pays by card.
3|600|TOEIC Part 5: adjective vs adverb after linking verbs|連結動詞のあとの形容詞(become / remain / seem)|become / remain / seem / look / feel のあとは形容詞を選ぶ。副詞は入らない。|seem + 形容詞;;remain + 形容詞|The price remained stable.=>価格は安定したままでした。||The price remained stably.
3|600|TOEIC Part 5: participle adjectives (-ing vs -ed)|分詞形容詞(-ing と -ed の選択)|感情を引き起こすものは -ing、感情を感じる人は -ed を選ぶ。|an interesting + 名詞;;be + interested in|The customers were satisfied with the service.=>客はサービスに満足していました。;;It was a disappointing result.=>がっかりな結果でした。||The customers were satisfying.
3|500|TOEIC Part 5: pronoun case (subject / object / possessive)|代名詞の格の選択(主格・目的格・所有格)|空所の位置が主語なら主格(I)、動詞・前置詞の目的語なら目的格(me)、名詞の前なら所有格(my)を選ぶ。|前置詞 + 目的格;;所有格 + 名詞;;主格 + 動詞|Please contact me if you need help.=>お困りのときは私に連絡してください。;;The manager and I will attend.=>部長と私が出席します。||The manager and me will attend.
3|600|TOEIC Part 5: possessive adjective vs possessive pronoun|所有格と所有代名詞|所有格(my)は名詞の前、所有代名詞(mine)は名詞なしで単独で使う。|my + 名詞;;mine / yours / theirs|The blue bag is mine.=>青いかばんは私のです。||The blue bag is my.
3|600|TOEIC Part 5: reflexive pronouns (by oneself / for oneself)|再帰代名詞の用法|主語と目的語が同じとき、または主語を強調するときに -self / -selves を使う。|by myself;;S + V + oneself|The staff prepared the room themselves.=>スタッフ自身が部屋を準備しました。
pre2|500|TOEIC Part 5: during vs while|during と while(前置詞と接続詞)|during のあとには名詞(句)、while のあとには S + V が続く。|during + 名詞;;while + S + V|We will be closed during the holidays.=>祝日のあいだは休業します。;;Please do not use your phone while you are driving.=>運転中は携帯電話を使わないでください。||during you are driving / while the holidays
pre2|730|TOEIC Part 5: conjunctive adverbs vs conjunctions|接続副詞と接続詞(however / although)|however はコンマを伴う副詞で文と文をつなぎ、although は節をつなぐ接続詞である。|S + V. However, S + V;;Although + S + V, S + V|The price is high. However, the quality is good.=>価格は高いですが、品質はよいです。||The price is high however the quality is good.
pre2|600|TOEIC Part 5: within vs in / for (periods of time)|within と in / for(期間の表し方)|within は「…以内に」、in は「…後に」、for は継続期間を表す。|within + 期間;;in + 期間;;for + 期間|Please reply within three days.=>3日以内にご返信ください。;;The shop will reopen in two weeks.=>店は2週間後に再開します。||Please reply for three days.
pre2|730|TOEIC Part 5: due to / owing to / thanks to|理由を表す前置詞句(due to / owing to / thanks to)|due to / owing to は理由、thanks to は良い理由に使う。後ろは名詞(句)で、S + V は続かない。|due to + 名詞;;owing to + 名詞;;thanks to + 名詞|Due to heavy snow, the road is closed.=>大雪のため道は閉鎖されています。||due to the snow fell
pre2|730|TOEIC Part 5: between vs among|between と among|2者の間は between、3者以上の間は among を使う。|between A and B;;among + 複数|The prize was shared among the staff.=>賞はスタッフの間で分けられました。||between three people
pre2|730|TOEIC Part 5: be + adjective + preposition (responsible for / capable of)|形容詞 + 前置詞の組み合わせ|形容詞ごとに決まった前置詞をとる。responsible for / capable of / aware of / familiar with など。|be responsible for;;be capable of;;be aware of;;be familiar with|He is responsible for the new project.=>彼は新しいプロジェクトを担当しています。||responsible of
pre2|730|TOEIC Part 5: verb + preposition (depend on / apply for / comply with)|動詞 + 前置詞の組み合わせ|動詞ごとに決まった前置詞をとる。depend on / apply for / comply with / consist of など。|depend on;;apply for;;comply with;;consist of|All visitors must comply with the rules.=>訪問者は規則に従わなければなりません。||comply to the rules
pre2|500|TOEIC Part 5: past simple with past time markers|過去を表す語句と過去形(yesterday / last / ago)|yesterday / last week / two days ago などがあれば過去形を選ぶ。現在完了は使えない。|yesterday + 過去形;;last + 期間 + 過去形;;期間 + ago + 過去形|We received your order yesterday.=>昨日ご注文を受け取りました。||We have received your order yesterday.

pre2|600|TOEIC Part 5: active vs passive voice choice|能動態と受動態の選択|空所のあとに目的語がなければ受動態(be + p.p.)、目的語があれば能動態を選ぶ。|S + V + O;;S + be + p.p. + (by ...)|The report was reviewed by the manager.=>報告書は部長が確認しました。||The report reviewed by the manager.
pre2|600|TOEIC Part 5: verbs taking -ing (avoid / consider / suggest / finish)|動名詞だけをとる動詞|avoid / consider / suggest / finish / enjoy / mind のあとは動名詞(-ing)。不定詞は続かない。|avoid + V-ing;;consider + V-ing;;suggest + V-ing|We are considering opening a new branch.=>新しい支店の開設を検討中です。||consider to open
pre2|600|TOEIC Part 5: verbs taking to V (agree / decide / plan / hope)|不定詞だけをとる動詞|agree / decide / plan / hope / expect / offer のあとは to + 動詞の原形。動名詞は続かない。|agree + to V;;decide + to V;;plan + to V|The board agreed to raise the price.=>役員会は値上げに同意しました。||agree raising
pre2|860|TOEIC Part 5: who vs whom|who と whom|関係節の中で主語の働きなら who、目的語の働きなら whom(前置詞のあとも whom)。|who + V;;whom + S + V;;前置詞 + whom|The person to whom you spoke is the manager.=>あなたが話した相手は部長です。
pre2|730|TOEIC Part 5: number vs amount|number と amount(可算・不可算)|可算名詞には a number of、不可算名詞には an amount of を使う。|a number of + 複数名詞;;an amount of + 不可算名詞|A large amount of rice was sold.=>大量の米が売れました。||a large number of rice
pre2|600|TOEIC Part 5: comparative form (than / much / far)|比較級の選択|空所の近くに than があれば比較級を選ぶ。比較級は much / far / even で強める。|比較級 + than;;much / far + 比較級|This plan is cheaper than the old one.=>この案は前の案より安いです。||more cheap than
