# 英語語彙データ（英検×TOEIC×分野）サマリー

`vocab.json`（11,514 項目）の人間向け説明。**公式の語彙表は英検にもTOEICにも存在しないため、ここでの「級」「スコア帯」はすべて推定**。個人学習用ゲームの出題・難易度調整の目安としてのみ使うこと。

## 1. ファイル
- `vocab.json` : 本体。`{word,pos,eiken,toeic,cefr,ja,domains,freq}` の配列。`freq` は頻度順位（1=最頻。wordfreq由来の原形ベース、約4万語中）。
- `domains.json` : 分野タグ35種の定義（日本語名・対象・想定ジョブ）。
- `scripts/` : `build_vocab.py`（生成）, `validate.py`（検証）, `make_report.py`（本ファイル生成）ほか。`overrides/` : 手書きの訳語・ブロックリスト、およびレベル見直し（`levels.tsv` = 英検/TOEICの上書き、`additions.tsv` = 追加語。`scripts/apply_levels.py` が適用）。`sources/` : 取得データ（`sources/README.md` にライセンス）。
- 再生成: venv に `wordfreq nltk lemminflect` と WordNet を用意し `python scripts/build_freq.py sources/wordfreq-derived/en_top60k.tsv && python scripts/build_vocab.py && python3 scripts/apply_review.py && python3 scripts/apply_levels.py && python3 -I scripts/validate.py && python3 scripts/make_report.py`。

### 2.2 英検の割り当て規則
1. 候補語: CEFR-J/Octanove の単語（品詞違いは別項目）＋ NGSL・TSL・BSL・NAWL、または頻度上位（原形順位8,500位以内かつNGSL31kで12,000位以内）の語のうち、EJDictに訳があり、WordNetに普通名詞等としてあるもの（固有名詞・卑語・屈折形・英国綴りの重複は除外）。
2. CEFRレベル: CEFR-J/Octanove のラベルをそのまま採用。それ以外の語は原形頻度順位で推定（〜3,000位=B1、〜7,000位=B2、〜13,000位=C1、それ以降=C2）。
3. 順序付け: `key = CEFR基準値(A1=0…C2=5) + 1.35 × (同一CEFR内の頻度パーセンタイル)`。係数1.35により隣接レベルが重なり合う（「A1–A2」のような級の曖昧さを再現）。A1/A2の具体名詞は −0.25〜−0.35、EJDict基本語リスト(850/2000語)は −0.10〜−0.25 の加点（学校で早く習う語を前に出す、学習指導要領の代理指標）。
4. 累積目標で切る: 5級=600、4級=1,300、3級=2,100、準2級=3,600、2級=5,100、準1級=7,500語まで。残りを1級とする。結果としておおむね 5級≒A1、4級≒A1〜A2、3級≒A2、準2級≒A2〜B1、2級≒B1、準1級≒B2、1級≒B2後半〜C2（下表）。
5. 品詞違いの別項目（例: `book` 名/動、`make` 名/動）は項目ごとに級を持つ。**「その単語の級」は同じ単語の項目のうち最も低い級**と読む。

### 2.3 TOEIC の割り当て規則
- 基礎スコア `s = ln(原形頻度順位)`。TSL収録語は `−(0.8〜1.5)`、BSL収録語は `−(0.8〜1.3)`（順位が高いほど大きく減点）、NAWL収録でTSL/BSLに無い語は `+0.35`（学術語は後ろへ）。
- `s` の昇順で累積 1,500 / 2,500 / 3,500 / 5,000 / 6,800 / 8,800 語を 〜400 / 〜500 / 〜600 / 〜730 / 〜860 / 〜990 に配分。残りは `null`（文学・学術・非常に低頻度などTOEICにほぼ出ない語）。
- 補正: 英検5/4/3級の語は TOEIC 400/500/600 を上限にする（基礎語は必ずスコア帯の下位）。TSL/BSL収録語は `null` にしない。準2・2級語も `null` にしない。
- 以上はTSL/BSLの順位と頻度だけに基づく推定で、実際の出題頻度の検証はしていない。

### 2.4 日本語訳（`ja`）
- 下書き: EJDict-hand の語義から、品詞に合う語義だけを選び、強調訳語（『』）を優先して最大3語・約26字に短縮（`scripts/gloss.py`）。
- 手書き: 5〜3級の大半、TOEIC頻出のTSL上位・BSL上位 約450語、EJDictに無い語・機能語・品詞が合わない語など、合計 2,745 項目（全体の24%）は、Claude が学習者向けに書いた訳（`overrides/gloss_*.txt`）。内訳（手書き項目数/その級の項目数）: 5級 603/666、4級 720/826、3級 634/1351、準2級 244/2188、2級 126/1308、準1級 138/1857、1級 280/3318。
- 見直し: 5級〜2級は `review/out_a/b/c.tsv`、準1級・1級（約5,100項目）は `review/out_d.tsv`（訳語・分野の全件見直し。誤訳・奇妙な訳・品詞違いの修正、約160項目のノイズ見出し語＝派生副詞・分詞・接辞断片など＝の削除は `review/drop.txt`、品詞の付け替えは `review/pos.tsv`、分野タグだけの修正は `review/domains.tsv`）を `scripts/apply_review.py` が適用する。
- 複数語見出し語: `ice cream` `post office` `check in` など日常・職場で必須の複合語・句動詞・定型表現（約245項目）は `overrides/additions.tsv` で追加（頻度順位は構成語の最も低頻度なものの1.5倍で代用）。
- 見直し後も機械抽出の語義が残る項目はある（EJDictは古い語義・文語的語義を含む）。

### 2.5 分野タグ（`domains`）
- 35種の固定タグ（§5）。語ごとに最大3つ。(a) 自作のシード語リスト（`scripts/domain_seeds.py`、各タグ50〜130語）、(b) WordNetの上位語（例: `food.n.01` `disease.n.01`）、(c) 日本語訳中のキーワード、(d) TSL/BSL収録語はしきい値を下げて業務系タグを付与、の得点合計がしきい値を超えたものを採用。どれにも当たらない語は `abstract`（抽象・機能語）。

## 3. 品質（実測）
`scripts/validate.py` は全項目のスキーマ・重複・件数範囲・基本語の整合性を検査（結果は§3.3）。
### 3.1 訳語のスポットチェック
5級〜2級: 見直し前（各級3%・計336項目、乱数シード固定: `scripts/sample.py`）で明らかな誤訳・断片化・品詞違い 18件（5.4%）、軽微な不自然さを含め約7%。見つかった誤りは個別に修正済み。
準1級・1級（全件見直し後）: 準1級・1級から無作為300項目を2回（シード20261114・777）目視。1回目で分野タグの誤り約11件（約4%）、訳語・品詞の誤り0〜2件を発見して分野修正をまとめて適用し、2回目の標本では訳語・品詞の誤り 約3件（約1%）・分野タグの誤り 約1件が残った。**準1級・1級の明らかな誤り（訳語・品詞・分野）の残存率は約2%（上限4%程度）**。ただし評価者は見直しをした本人（Claude）のみで、日本語ネイティブの専門家による検証ではないため過小評価の可能性が高い。語義の取りこぼしや「不自然ではないが学習者には低価値」な見出し語（`undiminishing` `recommendable` など派生語）は約2%残る。
### 3.2 分野タグのスポットチェック
別に無作為120項目（シード4242、最終版）を目視。`abstract` 以外のタグが付いた約55項目のうち、明らかに不適切なタグを含むものが約15件（27%）、やや怪しいものが約5件。主タグ（先頭）が妥当なのは約85%。`abstract` のみの約65項目のうち、本来は分野を持てる語（`fried` `smoke` `boy` など）が約10件。誤りの典型は多義語（`card`→manufacturing、`raise`→meetings/hr、`liner`→clothing）とWordNetの広い上位語の副作用。`abstract` は全体の約54%で、「分野を持たない語」と「推定できなかった語」が混在している。5〜3級（約2,100項目）は第1語義だけで判定する厳しめの設定にしてある。評価者は1人（Claude）のみ。
### 3.3 自動検証の結果
`python3 -I scripts/validate.py` → エラー0、警告3（訳語中の英語表記）（全項目のキー・語形・品詞/級/スコア帯/CEFR/分野の値域、(word,pos)重複なし、各級・各帯の件数が許容範囲、級ごとの頻度中央値が単調増加、頻度上位300語の整合性: 英検5〜3級に296語・TOEIC 400に300語）。

## 7. 既知の弱点・注意
1. **級・スコア帯は推定**。CEFR-JのCEFR付けと頻度に基づく機械的な切り分けであり、実際の英検の出題語彙とは一致しない。特に3級/準2級/2級の境界、1級の下限（B2後半を含む）は±1級程度ずれうる。
2. 準1級・1級（約5,000項目）は全件を見直し済みだが、残存誤りは約2%（実測は§3.1）。日本語ネイティブの専門家が全項目を確認したわけではない。
3. 品詞違いを別項目にしたため、同じ単語が別の級に現れる（`make` 動=5級／名=2級 など）。1語1級の表として使うなら単語ごとの最小値を取ること。
4. 分野タグは自動推定で、不適切なタグを含まない項目は約7割（主タグが妥当なのは約85%）。個々のジョブ・場面に使う前に目視確認を推奨。多義語は主要語義以外の分野が付くことがある。
5. TOEIC帯はTSL/BSL（Browne ら）と頻度の組み合わせによる推定。実際のL&R出題データでの検証は未実施。`null` は「TOEICに出ない」ではなく「出題が期待できる度合いが低い」。
6. 複数語見出し語（`ice cream` `check in` など）は職場ゲームで必要な約245項目だけ追加した（網羅ではない。慣用句は `phrases.json`）。英国綴りは米国綴りに統一（CEFR-Jの第一表記）。固有名詞は月・曜日・一部国籍のみ。ゲームの語彙が屈折形のまま（`telling` `books` `delivered` など）の場合は見出し語を足さず、原形＋forms で引く。
7. 英語の基本語でもEJDict-handに項目が無いもの（`story`, `color` 等）は手書き訳で補った。EJDictは古い語義が多く、現代的な語義（`keyboard`=キーボード等）の欠落があるため、TOEIC頻出語の一部は手で直した。
